# Recuperação da prova de API - Consumir API offline

# Instalação

- Utilizar VS Code, Python e Git

# Configuração e Execução

- Clonar o repositório com a API offline (https://github.com/jpsvalentim/api-meteorologica-offline.git)

- Criar uma venv (python -m venv .venv) e instalar as bibliotecas (pip install -r requirements.txt)

- Para iniciar, execute: uvicorn app.main:app --reload

- Verificar se o serviço está sendo executado na url disponibilizada.

- Em outra pasta, clone este repositório e crie novamente uma venv, instalando as bibliotecas necessárias (python -m pip install -r requirements.txt)

- Execute o Front-end através de: streamlit run frontend.py
